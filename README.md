# HENOSIS integrates single-cell data across species and distinct molecular feature spaces

# Main-figure analysis code

This directory organizes the analysis for Figures 1–6 by biological question and execution step. Each script or notebook has one defined role; separate preprocessing, statistical analysis and plotting steps remain separate.

| Figure | Analysis                                                                                    |
| ------ | ------------------------------------------------------------------------------------------- |
| 1      | Architecture diagrams; no analysis script in this package.                                  |
| 2      | Microglia gene-expression display and nine-species spermatogenesis transfer.                |
| 3      | Heart phylogeny, UMAP, conservation, evolutionary representation, orthology and expression. |
| 4      | Brain cell-type transfer and cross-fitted aging-state analysis.                             |
| 5      | Cerebellar scATAC motif and chromVAR analysis.                                              |
| 6      | PBMC and human–macaque RNA–ATAC gene/peak analyses.                                       |
