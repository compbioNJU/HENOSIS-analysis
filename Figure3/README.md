# Figure 3: Fifteen-species heart integration and molecular features

This directory automatically reproduces **3a–h** and generates some related extended analyses. Only unsupervised heart representations are used.

## Environment and paths

For environment installation, see the [project documentation](../README.md#2-install-the-environment). Public data used for this figure are available from [Zenodo: 10.5281/zenodo.23765892](https://doi.org/10.5281/zenodo.23765892).

Before running from this directory, you can set:

```bash
export ANALYSIS_DATA_DIR=/absolute/path/to/analysis_data
export ANALYSIS_RESULTS_DIR=/absolute/path/to/analysis_results
export PYTHON_BIN="$(command -v python)"
```

`ANALYSIS_DATA_DIR` should directly contain Figure2–6. If these variables are not set, the entry point reads from `analysis_data` beside the code package and writes results to `results` at the code-package root.

## Automatic execution

Run from this directory:

```bash
bash run_all.sh --check
bash run_all.sh --dry-run
bash run_all.sh
```

`--check` checks the data directory and import dependencies; `--dry-run` only displays commands; running without arguments executes the steps in order. Execution stops if any step fails. The script can also be invoked by absolute path from another working directory. Reruns may overwrite files with the same names, so use separate results directories for different runs.

## Execution order

The top-level `run_all.sh` calls `code/scripts/run_all.sh`:

1. `phylogenetic_tree/run.py`: divergence-time reference species tree (3a).
2. `umap/render.py --condition 15S`: unsupervised heart-cell UMAP (3b).
3. `expression/run.py`: species-level support tables derived from rankings and expression evidence.
4. `expression/plot_four_species_cardiomyocyte.py`: cardiomyocyte gene display for four species (3h).
5. `expression/plot_all_species_by_celltype.py`: related expression displays across fifteen species.
6. `conservation/run.py`: cell-class centroids, cross-species similarities and cardiomyocyte heatmaps (3c, 3f and related extended analyses).
7. `evolutionary_representation/run.py`: species-pair group comparisons, mean similarities and cell-class matching advantage (3c–e).
8. `orthology_identity/run.py`: human-referenced orthology annotations combined with source-expression support (3g).

All paths above are relative to `code/scripts/`. Subsequent expression plots and species-pair comparisons depend on tables generated by earlier steps; run the steps in order.

## Inputs and outputs

Inputs are configured in `code/config/inputs.yaml`, with paths relative to `analysis_data`: the integrated heart H5AD, rankings, expression matrices for fifteen species, orthology tables, expression evidence and divergence-time table. Species display names and color configurations are stored in `code/config/`.

When run through the main entry point, results are written to `$ANALYSIS_RESULTS_DIR/Figure3/`, in separate directories for the species tree, UMAP, expression, similarity, species-pair comparisons and orthology analyses.
